# 7dtd-vision-review

**deadeye** — the shared vision-model review gateway for hordeforge. Forwards
frames or a muxed clip plus recorded intent to a configured vision model and
returns structured, advisory feedback in one stable result shape.

Consumed programmatically by `7dtd-asset-pipeline` (`shamway review-video`)
and `7dtd-playtest` (`review_video.py`); usable standalone. CLI first; an MCP
server surface is planned.

Docs land with the feature work.
